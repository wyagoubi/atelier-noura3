# Atelier Noura

نسخة أولى بسيطة من متجر Atelier Noura.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو ارفع المشروع إلى GitHub ثم انشره عبر Vercel.

## النسخة الحالية
- واجهة عربية RTL.
- تصميم راقٍ Responsive.
- منتجات وتصنيفات.
- سلة باستخدام localStorage.
- نموذج طلب.
- صفحة نجاح.
- لوحة إدارية محلية في `admin.html`.

## المرحلة التالية
ربط Supabase لحفظ المنتجات والطلبات والصور فعليًا، مع تسجيل دخول المسؤول وRLS وStorage.
